# 难度评估框架

> 难度是相对概念，综合多维度判断，并务必用「当年 + 官方」数据。

## 六维度

1. **院校层次**：清北 / C9 / 985 / 211 / 双一流 / 双非。
2. **学科评估**：教育部学科评估（如第四轮 2017 年公开）的 A+/A/A-/B+/B…，反映学科实力；注意轮次，最新结果以官方公布为准。
3. **复试线溢价**：复试线相对国家线的差值；越高越难。
4. **报录比与统考名额**：报考/录取比例；统考名额 = 招生总人数 − 推免人数，名额越少越难。
5. **专业课难度**：408（公开稳定但量大）vs 自命题（范围小但不确定性强）。
6. **公平性口碑**：是否保护一志愿、是否歧视本科出身、复试占比（复试占比高则面试影响大）。

## 国家线（A 区 / B 区）

- A 区：北京、天津、河北、山西、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、重庆、四川、陕西 等。
- B 区：内蒙古、广西、海南、贵州、云南、西藏、甘肃、青海、宁夏、新疆 等。
- 分「学术学位」与「专业学位」、按门类（工学）分别划线，A 区通常高于 B 区。
- 国家线每年 3 月公布，是复试与调剂的最低门槛。

## 关键指标定义

- 复试线：进入复试的最低初试分（可能分单科线与总分线）。
- 报录比 = 报考人数 / 录取人数。
- 差额复试：进入复试人数多于录取人数（常见 1:1.2 ~ 1:1.5）。
- 推免：推荐免试（保研），占用招生名额；统考名额 = 招生计划 − 推免。

## 难度定档建议（经验性，仅辅助）

- 顶级：清北、强学科评估 A+ 的院校热门方向。
- 高：985/强 211 的 A/A- 方向、热门 408。
- 中：211/双一流或强势双非的常规方向。
- 相对温和：双非且招生名额较多、复试线接近国家线的方向。

> 以上仅为粗略分层，务必用当年官方数据佐证。
