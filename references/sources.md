# 权威来源清单与检索用法

> 原则：官方优先（研招网 + 院校官网），第三方只作参考并标注性质。

## 官方（最高优先级）

| 来源 | 链接 | 用途 |
|---|---|---|
| 中国研究生招生信息网（研招网） | https://yz.chsi.com.cn | 报名、调剂、政策、院校库、专业目录 |
| 研招网专业目录 | https://yz.chsi.com.cn/zsml/ | 按专业/院校查招生单位、研究方向、考试科目 |
| 研招网院校库 | https://yz.chsi.com.cn/sch/ | 按院校查招生简章、专业目录 |
| 研招网调剂系统 | https://yz.chsi.com.cn/yztj/ | 调剂信息与申请 |
| 教育部学位与研究生教育发展中心 | https://www.cdgdc.edu.cn | 学科评估结果 |
| 各校研究生院 / 研招网官网 | 搜索「XX大学 研究生招生」 | 招生简章、专业目录、考试大纲、参考书、复试线、复试名单 |

## 参考/排名（辅助，标注性质）

| 来源 | 用途 |
|---|---|
| 软科、校友会、QS 等排名 | 院校综合参考（非官方，注意口径） |
| 各校研究生院「信息公开/录取公示」 | 报录比、录取名单（最可信的报录数据来源） |

## 社区与讨论（参考，需交叉验证）

- 考研论坛、知乎、贴吧、B 站等：择校经验、难度口碑、真题回忆。
- 注意：真实性参差，重要结论务必回到官方核实。

## 检索语句模板

- 院校官网：`site:XX大学域名 研究生 招生 202X 计算机`
- 研招网专业目录：按「专业代码 081200 / 085404」查询。
- 复试线：`XX大学 202X 计算机 复试线`，优先官网。
- 报录比：`XX大学 202X 计算机 报录比 录取`，优先学校研究生院公示。
- 大纲/参考书：`XX大学 202X 计算机 考研 大纲 参考书目`。

## 核实清单（每次给出结论前）

- [ ] 数据是哪一年？
- [ ] 来源是官方还是第三方？
- [ ] 考试科目/参考书是否来自当年招生目录？
- [ ] 招生人数是否已剔除推免？
