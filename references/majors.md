## 常见研究方向（跨学硕/专硕通用）

- 人工智能 / 机器学习 / 深度学习 / 自然语言处理 / 计算机视觉
- 大数据 / 数据挖掘 / 数据科学
- 网络 / 网络安全 / 信息安全 / 密码学
- 系统 / 体系结构 / 高性能计算 / 分布式系统 / 云计算
- 软件工程 / 程序分析 / 形式化方法
- 数据库 / 知识工程
- 图形图像 / 虚拟现实 / 多媒体
- 嵌入式 / 物联网 / 边缘计算
- 理论计算机 / 算法 / 复杂性

## 选方向建议（框架）

1. 看兴趣 + 已有基础（算法/数学/系统/网络哪方面强）。
2. 看目标：读博走学术 → 优先学硕 + 有导师方向对口的强学科评估院校；就业 → 专硕/应用方向亦可，关注实习与地域。
3. 看导师：方向热度、课题组、毕业生去向（去目标院校官网查导师主页与招生信息）。
4. 看统考名额：部分院校热门方向推免占比高，统考名额少（需查当年招生目录）。
