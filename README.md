# 🎓 kaoyan-cs — 计算机考研信息查找技能

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供的计算机考研信息查找技能（Skill）。加载后，模型会自动遵循一套系统化的择校查证方法论，覆盖学硕/专硕全方向、权威来源、408/自命题、难度评估、时间线与资料检索。

---

## ✨ 功能

| 能力 | 说明 |
|---|---|
| 五步查证法 | 定方向 → 圈院校 → 查官方数据 → 估难度 → 汇总结论 |
| 权威来源清单 | 研招网、各校研究生院、学科评估等官方渠道 |
| 稳定常识库 | 专业代码（0812/0835/0839/0854）、初试科目、408 组成、数学一/二、英语一/二、学硕/专硕区别 |
| 难度评估框架 | 六维度（层次/评估/复试线/报录比/专业课/公平性） |
| 资料检索指引 | 教材、辅导书、真题、课程来源 |
| 5 份参考资料 | 专业代码、初试科目、难度框架、时间线、权威来源 |

## 📦 安装

### 方法 1：git clone + 复制（推荐）

```bash
# 1. 克隆仓库
git clone https://github.com/jiangjank2-arch/kaoyan-cs.git

# 2a. 全局安装（所有项目可用）
cp -r kaoyan-cs ~/.dsh/skills/

# 2b. 或项目级安装（仅当前项目可用）
mkdir -p .dsh/skills
cp -r kaoyan-cs .dsh/skills/
```

### 方法 2：直接下载

从 GitHub Releases 下载 zip，解压后把 `kaoyan-cs` 文件夹复制到 `~/.dsh/skills/` 下。

### 方法 3：项目级安装（Windows）

```powershell
# 在你的项目根目录下
New-Item -ItemType Directory -Force -Path .dsh\skills
Copy-Item -Recurse kaoyan-cs .dsh\skills\
```

安装后 **重启 DSH** 即可。模型会在遇到考研相关问题时自动加载该技能。

### 验证安装

重启后开一个新会话，问一句「帮我查学科评估 A+ 的计算机考研院校」，如果模型按五步查证法回答，说明技能已生效。

## 🧠 技能内容预览

加载后，模型会遵循 `SKILL.md` 中的指令：

### 五步查证法

1. **定方向**：确定学硕/专硕与专业代码（见 `references/majors.md`）
2. **圈院校**：按层次 + 学科评估 + 地域圈定 3~10 所，形成冲/稳/保梯队
3. **查官方数据**：逐校在研招网 + 院校官网核实科目、名额、复试线
4. **估难度**：综合复试线、报录比、统考名额、408/自命题、公平性口碑
5. **汇总结论**：输出结构化对比表，标注数字来源与年份

### 核心规则

- **年度数据必须联网核实**：复试线、报录比等每年变化，给数字必须标注「年份 + 来源」
- **官方优先**：考试科目/参考书以研招网 + 院校官网为准
- **如实说明不确定性**：查不到就说「未找到官方数据」，不编造
- **区分稳定常识 vs 年度数据**：专业代码/408 组成可直接使用，分数线必须核实

## 🔧 扩展

### 添加真实院校数据

编辑 `references/majors.md` 中的内容，补充你目标院校的具体信息（科目、分数线、报录比等），然后重新提交。

### 与 dsh-kaoyan 插件配合

两者可以单独使用，也可以一起使用：

| 层级 | 交付物 | 说明 |
|---|---|---|
| **Skill**（本项目） | `kaoyan-cs` | 方法论 + 权威来源 + 稳定常识，模型自动加载 |
| **Plugin** | `dsh-kaoyan` | `kaoyan_schools`（院校查询）+ `kaoyan_guide`（指南），模型可调用工具 |

- **只装技能**：模型用知识和联网搜索回答，适合了解方法论和查找指引
- **只装插件**：模型调用结构化工具查询内置数据，适合快速查表
- **都装**：技能给方法论，插件给结构数据，互补效果最佳

```
帮我查学科评估 A+ 的计算机考研院校

对比西安交通大学和西电的计算机专硕

考研时间线是怎样的
帮我找一下数据结构的参考书
```

模型会自动加载技能，按五步查证法给出结构化回答。

## ⚠️ 免责声明

本技能内置资料库为**示例数据**：

- 院校层次、学科评估（第四轮公开结果）为较稳定的公开信息
- 初试科目、难度档、招生名额等**每年可能变化**
- 所有年度性数据必须以 [研招网](https://yz.chsi.com.cn) 与目标院校研究生院官网当年数据为准
